# Corpus Texts

The active corpus contains 318 texts, but the full primary-text collection is not yet distributed through this repository.

Before any text is uploaded, it will be reviewed for:

- public-domain status;
- source repository and acquisition route;
- edition and translation provenance;
- OCR quality;
- redistribution conditions; and
- whether linking to the source is preferable to reproducing the text.

Future subdirectories may distinguish public-domain files, restricted or link-only records, OCR drafts, and excluded provenance witnesses. Absence from this directory does not mean that a text is absent from the research corpus.
