# Metadata

This directory will contain the auditable records that describe the active corpus and its revision history.

Planned files:

- `corpus_manifest.csv`: one row per active corpus item
- `exclusion_log.csv`: excluded, deferred, or superseded items and reasons
- `duplicate_log.csv`: duplicate and near-duplicate adjudications
- `translation_log.csv`: translated works and retained or excluded witnesses
- `bibliography.csv`: source and publication information where verified

Metadata fields will distinguish verified information from inherited, provisional, unresolved, or OCR-derived information. Missing fields will remain blank or explicitly marked unresolved rather than inferred without evidence.
