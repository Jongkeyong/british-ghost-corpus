# Results and Derived Materials

This directory is reserved for outputs derived from a documented corpus version, including descriptive statistics, tables, figures, network exports, and selected analytical results.

Every deposited result should identify:

- the corpus version and active-text count;
- the input manifest or cohort;
- the script, notebook, model, or prompt used;
- parameters and software or model versions;
- the date of generation;
- whether the output was manually reviewed; and
- known interpretive or technical limitations.

Statistical difference is not treated here as self-evident literary significance. Candidate outliers, network patterns, and classifications require historical and close-reading interpretation.
