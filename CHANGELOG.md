# Changelog

All notable changes to the active corpus and repository documentation will be recorded here.

## [0.3] — 2026-07-20

### Active corpus

- Established the current release as **British Ghost Corpus: Deduplicated Translations**.
- Confirmed **318 active texts** dated **1764–1913**.
- Excluded one near-exact duplicate from the active set while retaining its provenance record.
- Excluded one alternate English translation of a Maupassant story already represented in the active set while retaining the alternate witness in provenance storage.
- Clarified that alternate translations may be preserved without being counted as separate active literary works.

### Documentation

- Added a committee-facing repository README.
- Added `CORPUS_SCOPE.md`.
- Added `METHODOLOGY.md`.
- Added `DATA_STATEMENT.md`.
- Added citation metadata and release structure.

## [0.2] — 2026

- Expanded the corpus from 317 to 320 records through researcher-directed canonical and boundary review.
- Added *The Castle of Otranto*, “My Aunt Margaret’s Mirror,” and *The Monk: A Romance*.
- Confirmed that *The Canterville Ghost* was already present and did not duplicate it.

## [0.1] — 2026

- Built the earliest fully auditable 175-item discovery corpus.
- Added 62 screened works to reach 237 items.
- Added 48 works through a gender-recovery pass to reach 285 items.
- Added 32 works through a diversity-recovery pass to reach 317 items.

## Unreleased

Planned additions include the active manifest, exclusion and duplicate logs, translation relations, source provenance, text-quality flags, bibliographic normalization notes, and reproducibility scripts.
